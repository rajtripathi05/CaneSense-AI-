# Sample data

All files are **synthetic**, generated by `canesense/data.py` (seed 42). No real farms or farmers.

- `sample_plots.csv` - 28 plots, 6 fictional villages, coordinates, crop stage, soil, irrigation system
- `sample_observations_last21d.csv` - daily synthetic sensor/weather observations, last 21 days
- `sample_recommendations_normal.csv` - model predictions and recommendations for Normal Conditions
